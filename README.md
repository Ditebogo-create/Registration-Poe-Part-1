# Registration-POE-Part-1

Java console app for user registration and login functionality.

## Features
- Username validation: must contain underscore and <=5 characters
- Password validation: >=8 chars, 1 capital, 1 number, 1 special char
- Cellphone validation: +27 format
- Registration and Login system

## How to Run
1. Clone repo
2. Open in NetBeans / IntelliJ / VS Code
3. Run Main.java
4. Follow console instructions

## Tech Stack
Java, Maven, JUnit
